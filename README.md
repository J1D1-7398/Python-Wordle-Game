# Python-Wordle-Game
A game of wordle implemented in python! No more boring waiting, fire up a terminal and play a fun very known game!

It is coded for Linux, but it should work correctly on MacOS
For Windows, just change this line:
```
subprocess.call("clear")
```
For this one:
```
subprocess.call("cls")
```

##How to use
Open a terminal window and navigate to the folder where you cloned this repo.
Enter the "Code" folder and launch the script with:
```
python WordleGame.py
```
Or for python3:
```
python3 WordleGame.py
```

It should work fine!
